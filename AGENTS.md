# Substack website guide

Read `README.md` before starting a user's website project. It contains the beginner workflow and the implementation instructions.

When the user asks to build their own website using this guide:

- Ask for their exact publication/personal links and design preferences before implementation.
- Use their own branding, articles, categories, and selected image variants.
- Summarize the agreed plan, build a working preview, and incorporate feedback.
- Get approval of the preview before publishing to the user's own deployment account.
- Deliver working website files, verified links, and clear update instructions.

This repository is a reusable guide. Build the user's website in their chosen project folder; no application build or deployment configuration is required to read this guide.

If the task is to maintain the guide itself, edit the documentation as requested. The guide's discovery and deployment steps apply to website builds, not to routine documentation edits.
